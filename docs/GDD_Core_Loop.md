# 鱼人逆袭：潮涌军团 — 核心循环设计文档

> **品类**：Survivors-like 割草 + 角色收集养成  
> **平台**：抖音小游戏（Godot 4.5 + WebGL）  
> **操作**：单手（虚拟摇杆移动，其余全自动）  
> **单局时长**：10-15 分钟/关（完整构筑体验）  
> **关卡结构**：5大章节 × 4-5关，线性推图  
> **核心幻想**：鱼人大军从深海崛起，一路屠杀正派势力，攻陷人类王城  

---

## 二、局内系统

### 2.1 操作方式

| 操作 | 方式 | 说明 |
|------|------|------|
| 移动 | 左手虚拟摇杆 | 唯一的主动操作 |
| 攻击 | 全自动 | 主角+队友各自按攻击间隔自动输出 |
| 大招 | 自动释放 | 充能满后自动触发，无需手动 |
| 拾取 | 自动吸附 | 经验宝石/金币在一定范围内自动飞向玩家 |

**设计原则**：玩家只需要思考"往哪走"——靠近敌群 = 冒险高收益，远离 = 安全低收益。

### 2.2 招募系统（核心差异化）

#### 升级时的选择

玩家每次升级，弹出 **3选1** 面板：

```
┌─────────┐  ┌─────────┐  ┌─────────┐
│ 🐡 河豚  │  │ ⚡ 电鳗  │  │ 🦑 章鱼  │
│ 近战坦克 │  │ 链式远程 │  │ 范围控制 │
│ [招募]   │  │ [招募]   │  │ [升星★]  │
└─────────┘  └─────────┘  └─────────┘
```

- **招募**：新队友加入，跟随主角，自动攻击
- **升星**：已有队友再次出现 → 合并升星（★→★★→★★★），属性+技能强化

#### 队友跟随与阵型

```
        [远程C]     [远程D]
           \         /
    [近战B] ● 主角 ● [近战A]
           /         \
        [远程E]     [远程F]
```

- 近战队友：贴近主角，环绕保护
- 远程队友：外圈站位，向最近敌人射击
- 队友数量上限：**8个**（视觉清晰度 + 性能平衡）
- 超过上限后，升级选项变为"升星已有队友"或"被动增益"

#### 视觉成长感

| 阶段 | 队伍规模 | 视觉表现 |
|------|----------|----------|
| 开局 | 主角 + 1初始队友 | 孤独，小心翼翼 |
| 中期 | 主角 + 4-5队友 | 小队成型，火力覆盖 |
| 后期 | 主角 + 8队友（多个★★★） | 鱼人军团，弹幕铺满屏幕 |

### 2.3 大招系统

**充能方式**：杀敌积攒能量条（屏幕顶部显示）

**释放方式**：充满后 **自动释放**（方案A）

**大招效果由主角决定**：
- 每个主角鱼人有独特大招
- 大招释放时，所有队友也会触发"协同效果"（短暂攻速翻倍/全体回血等）

**大招频率**：约每 30-45 秒一次（保证每局能放 8-12 次）

### 2.4 敌人设计

#### 正派阵营（敌方）— 按章节递进

| 类型 | 行为 | 首次出现 |
|------|------|----------|
| 变异鱼 | 直线冲锋，低血低攻 | 第1章 |
| 渔夫 | 近战砍击，中等属性 | 第2章 |
| 猎人 | 远程射击，站定不动 | 第2章 |
| 民兵 | 直线冲锋，数量多 | 第2章 |
| 骑士 | 高血高攻，冲锋 | 第3章 |
| 弓箭手 | 远程射击，移动射击 | 第3章 |
| 法师 | 远程AOE，间歇施法 | 第3章 |
| 牧师 | 治疗周围友军 | 第4章 |
| 圣骑士 | 高血+护盾+冲锋 | 第4章 |
| 禁卫军 | 全属性高，协同作战 | 第5章 |

#### 单关刷怪节奏（时间轴驱动，参考弹壳特工队）

怪物**持续不断刷新**，密度随时间递增，不是"清完一波等下一波"：

```
时间轴（15分钟关）：
0───2───3───4───5───7───8───9───10──12──13──14──15
│   │   │   │   │   │   │   │   │   │   │   │   │
小怪 +新种 尸潮① +精英 BOSS1 恢复 尸潮② +新种 BOSS2 加速 尸潮③ 地狱 BOSS3
逐增  逐增 高密度 出现  清场  缓冲 高密度 逐增  清场  满屏 极限  满屏 最终
                       ↑                    ↑              ↑
                   计时暂停              计时暂停       击杀=通关
```

**核心规则**：
- 怪物持续刷新，密度随时间线性递增
- **尸潮**（3/8/13分钟）：短时间大量怪物涌入，构筑质量的"考试"
- **Boss**（5/10/15分钟）：出场瞬间**秒杀全场小怪**（喘息点），缩小活动范围
- Boss战时**计时暂停**，不浪费玩家成长时间
- 最终Boss击杀 = 通关，活到15分钟但没杀死最终Boss = 失败

**升级频率**：约每 45-60 秒升一次，单局升级 **12-18 次**（保证构筑爽感）

### 2.5 单局流程

```
[选人] → [进场] → [苟活期 0-5min] → [成长期 5-10min] → [碾压期 10-15min] → [结算]
                        ↑                   ↑                    ↑
                   队伍1-3人            队伍5-6人             队伍满编8人
                   小心走位            火力成型              割草爽感爆发
```

**构筑爽感曲线（先苦后甜）**：
```
队伍火力
  ▲
  │                              ████████  碾压（满编+多个★★★）
  │                         ████
  │                    ████
  │               ████          ← 成型点（7-8分钟）
  │          ████
  │     ████
  │ ████
  ├──┼──┼──┼──┼──┼──┼──┼──→ 时间(分钟)
  0  2  4  6  8  10 12 15
     苟活期      成长期      碾压期
```

- 单关时长 **10-15 分钟**（教学关8分钟，正常关12-15分钟）
- 怪物持续刷新 + 3次Boss节点
- 通关 = 击杀最终Boss，失败 = 主角死亡
- 每局升级 12-18 次，构筑体验完整

## 四、章节推图系统（核心进度框架）

### 4.1 世界观路线

鱼人大军从深海出发，一路屠杀正派势力据点，最终攻陷人类王城：

```
第一章：深海觉醒 → 第二章：沿海渔村 → 第三章：平原城镇 → 第四章：圣殿山脉 → 第五章：人类王城
   鱼人巢穴          屠渔民猎人         攻城镇守军         攻教廷圣骑士        最终决战
```

### 4.2 章节结构

每章 = **4-5个关卡**（每关10-15分钟，完整构筑体验）

```
章节1·深海觉醒（4关）
├── 1-1  教学关（8分钟，简化版，学移动+招募）
├── 1-2  正常关（12分钟）
├── 1-3  正常关（15分钟）
└── 1-4  ★Boss关（15分钟，章节Boss为最终Boss）

章节2·沿海渔村（5关）
├── 2-1 ~ 2-3  正常关（15分钟）
├── 2-4  精英关（15分钟，精英怪更多更早出现）
└── 2-5  ★Boss关（15分钟）

章节3·平原城镇（5关）
├── 3-1 ~ 3-3  正常关（15分钟）
├── 3-4  精英关
└── 3-5  ★Boss关

章节4·圣殿山脉（5关）
├── 4-1 ~ 4-3  正常关（15分钟）
├── 4-4  精英关
└── 4-5  ★Boss关

章节5·人类王城（5关）
├── 5-1 ~ 5-3  正常关（15分钟）
├── 5-4  精英关
└── 5-5  ★最终Boss关（屠龙勇者）
```

总计 **24关**，首通总时长约 5-6 小时。

### 4.3 每关内部结构（时间轴驱动）

```
时间轴（15分钟标准关）：

[0-5min 苟活期]
  - 怪物少量持续刷新，密度缓慢递增
  - 2分钟出现新怪种
  - 3分钟：尸潮①（短时高密度，20秒）
  - 玩家升级约5-6次，队伍从2人→4人

[5min BOSS①]
  - 出场秒杀全场小怪（喘息）
  - 活动范围缩小
  - 计时暂停
  - 击杀后恢复正常，掉落大量经验

[5-10min 成长期]
  - 怪物密度中等，新怪种加入
  - 8分钟：尸潮②（更高密度，25秒）
  - 精英怪开始出现
  - 玩家升级约4-5次，队伍从4人→6-7人

[10min BOSS②]
  - 同上，更强的Boss
  - 击杀后进入最终阶段

[10-15min 碾压期]
  - 怪物密度极高（满屏）
  - 13分钟：尸潮③（地狱级密度，30秒）
  - 玩家队伍满编，火力全开，割草爽感
  - 升级约3-4次（主要是升星已有队友）

[15min 最终BOSS]
  - 章节Boss / 关卡最终Boss
  - 击杀 = 通关
```

- Boss出场**秒杀全场小怪** → 清场喘息 + 聚焦Boss战
- Boss战时**计时暂停** → 不浪费成长时间
- Boss战时**缩小活动范围** → 增加紧张感
- 尸潮是Boss前的"考试" → 构筑不够强这里就会死

### 4.6 难度曲线 & 卡关设计

```
章节1: 纯教学，不卡人，保证新手体验
章节2: 开始需要升级主角才能过（Lv3-4）
章节3: 需要特定队友组合 / 队友升星
章节4: 硬数值墙，逼局外养成（主角Lv7+）
章节5: 满配才能通关（主角Lv10 + 多个★★★队友）
```

### 4.7 三星评价系统

每关通关后根据表现给 1-3 星：

| 星级 | 条件 | 额外奖励 |
|------|------|----------|
| ★ | 通关（击杀最终Boss） | 基础金币 |
| ★★ | 通关 + 主角血量 > 50% | 金币x1.5 |
| ★★★ | 通关 + 主角血量 > 80% + 未使用复活 | 金币x2 + 碎片 |

累计星数解锁章节宝箱（每章 6/9/12 星各一个）。

### 4.8 协同效果（羁绊系统）

特定队友组合触发额外增益：

| 组合 | 条件 | 效果 |
|------|------|------|
| 鱼人军团 | 猎潮者 + 战争队长 + 唤潮者 | 全队攻速+15% |
| 暗影双刃 | 夜行者 + 潜伏者 | 毒伤+30%，陷阱触发时额外中毒 |
| 巫医祝福 | 巫医 + 先知 | 闪电链命中时回复全队少量HP |
| 铁壁前线 | 螃蟹人利爪 + 螃蟹人爆破蟹 + 战争队长 | 近战队友减伤20% |
| 远程压制 | 猎潮者 + 掠袭者 | 远程穿透+1，弹速+20% |
| 毒潮 | 水母 + 海胆 | 敌人持续掉血（全图DOT） |

## 五、商业化设计

### 5.1 广告点位

## 六、技术要点（Godot 4.5）

### 6.1 性能关键

| 挑战 | 方案 |
|------|------|
| 200+敌人同屏 | MultiMeshInstance2D 渲染 + 自定义逻辑（不用节点树） |
| 队友跟随 | 简单的 Boid 算法（分离+聚合+对齐），不用 NavigationAgent |
| 弹幕/投射物 | 对象池，预分配 200 个，循环复用 |
| 碰撞检测 | 空间哈希网格（自写），不用 Godot 物理引擎 |
| 经验宝石吸附 | 简单 lerp 向玩家移动，不用 Area2D |
